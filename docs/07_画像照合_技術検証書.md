# 画像照合 技術検証書

> Status: Draft

## 目的

現地で撮影した画像とサーバー上の参照画像を比較し、スポット到達を判定できるか検証する。

## セキュリティ境界

- 参照画像と照合しきい値はサーバーだけに配置する
- `data/verify.server.json` をクライアントへバンドルしない
- アップロード画像のサイズ、形式、処理時間を制限する

## 検証手順

1. 各スポットの参照画像を複数条件で撮影する
2. `reference/PhotoVerifyLab.jsx` で候補しきい値を比較する
3. 成功例と失敗例を分けて測定する
4. 採用値と判断根拠を本書へ記録する
