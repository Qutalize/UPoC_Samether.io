## 2. 画面別の変更差分

### 2.1 全画面共通
- **フォント変更**: `Times New Roman / Georgia`（serif）→ 丸ゴシック系ポップフォント。Web Fonts推奨: **M PLUS Rounded 1c**（日本語対応・Google Fonts）。英字見出しは **Baloo 2** など
- **ボタン**: `styledButton.ts` の「─ ラベル ─」形式（罫線装飾）→ 角丸パディング付きピル型ボタン（塗り + ドロップシャドウ + 押下時スケール0.95）
- カラー定義を `client/src/theme.ts` に一元化（現状約20ファイルにハードコード。詳細は実装アドバイス参照）

### 2.2 GameScene（ゲーム本編）
- `BackgroundShader.ts`: 暗い深海ノイズ → 明るい水面コースティクス（波の光模様）。シェーダのベースカラーを `#0096C7` 系に変更し、白いハイライト（泡・光条）を追加
- HUD（XpBar/Leaderboard/Radar）: 黒半透明パネル → 白半透明パネル + ティール文字
- ジョイスティック: 白半透明ベース + コーラル輝線

### 2.3 HomeScreen
- タイトル「S A M E T H E R . I O」→「**UECPort SAMEZARIO 〜調布のうみ〜**」（仮）ロゴ。虹色 or サンセットグラデ文字
- 背景に装飾: ヤシの木・波・雲のシルエット（SVG/PNG 2〜3枚で十分、発表映え重視）
- ステージマップへの導線ボタン「調布のマップへ」を最上位CTAに

### 2.4 ステージ選択マップ（新規画面）
- MapLibre（既存Map流用）で調布市域を表示、京王線ラインを強調
- 未解放エリア: クラウドグレーの半透明ポリゴン + 錠前アイコン
- 解放済みエリア: マスク除去 + パームグリーンの縁取り + 歴史スポット赤ピン
- 深大寺（ラスボス）: 濃緑の森 + ボスシルエット。全解放まで「???」表示
- タップで下からボトムシートが出現し、ステージ情報（解放条件・スポット写真・挑戦ボタン）を表示

### 2.5 照合・解放演出（新規）
1. アップロード中: 波形ローディング
2. 成功: 画面フラッシュ（白→パームグリーン）+「エリア解放！」バッジ + 紙吹雪パーティクル（Phaser emitter）
3. マップに切替 → グレーマスクがフェードアウト → **赤ピンが上空からドロップ、2回バウンド**（CSS keyframes または MapLibre Marker + アニメーション。実装アドバイス参照）
4. 効果音: 既存 `sfx_levelup.mp3` 流用可

### 2.6 サメ・キャラクター
- 既存サメ画像はそのまま流用（工数削減）。ただし彩度+10〜20%の一括補正で明るいトーンに馴染ませる（ImageMagick一括処理で30分作業）
- 余裕があればStage1の敵に「カラフルな熱帯魚」テクスチャ追加

## 3. トーン&マナー原則

| 原則 | 内容 |
|---|---|
| 明るい・ポップ | 高彩度・高明度。黒の多用禁止（影はティール系 `#073B4C` @ 20%で代替） |
| 丸い | 角丸12〜16px、丸ゴシック、円形アイコンで統一 |
| 発表映え | プロジェクタ投影を想定しコントラスト比4.5:1以上を維持（特に白背景+黄色の組合せは避ける） |
| 地域色 | 京王線カラー（`#DD0077` 系）をステージマップの路線表示に使用し「調布らしさ」を出す |
