## 3. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 写真照合の精度が出ない（天候・時間帯で見え方が変わる） | M3遅延 | 参照画像を時間帯別に複数枚用意 + しきい値緩め + **ジオフェンスを主判定にする逃げ道**を設計段階で確保（照合はゆるく、位置は厳密に） |
| メンバーの試験期間と重複 | 全体遅延 | W3-W4のタスクは相互依存を減らして並列化済み。最悪 F-08/F-15/ボス演出 を審査後送りにする優先度を事前合意 |
| iOS Safariのカメラ/位置情報の挙動差 | M3遅延 | W3前半で実機検証タスク(3-5)を最優先。HTTPSでの動作確認必須 |
| Xのシェア検証ができない（API有料） | F-10仕様 | 「シェア画面を開いた時点で付与」に仕様を割り切る（要件定義に明記済み） |
