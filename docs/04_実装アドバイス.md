# 実装アドバイス

> Status: Draft

## 基本方針

- 既存の Phaser 3 + TypeScript + Vite / Go 構成を拡張する
- サーバーをゲーム状態の正として扱う
- 大きな既存ファイルへ機能を集中させず、責務ごとに分離する
- 新規ライブラリを追加する前に既存の仕組みで実現できるか確認する

## 変更時の注意

- WebSocket プロトコルはクライアントとサーバーを対で変更する
- 進捗は完全なスナップショットで置換し、差分加算しない
- 照合用の参照画像やしきい値をクライアントへ配布しない
