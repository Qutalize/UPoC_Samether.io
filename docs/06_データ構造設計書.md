# データ構造設計書

> Status: Draft

## 一次定義

共有する型の初期案は `data/uecport-types.ts`、静的データは `data/*.json` を参照する。

## ステージ

- ステージは複数の撮影スポットを持つ
- スポットは公開識別子、表示情報、解放条件を持つ
- 照合に用いる秘密情報は公開マスタから分離する

## 進捗

- 進捗はユーザー単位の完全なスナップショットとして扱う
- 更新日時は ISO 8601 形式で保持する
- TODO: Redis のキー、TTL、競合時の更新規則を定義する

## バージョニング

- JSONには `version` を持たせ、破壊的変更時に更新する
