## 前提

- クライアントは Phaser 3 + TypeScript + Vite を継続利用する
- サーバーは既存の Go 実装を拡張する
- `reference/*.jsx` は UI 参考資料であり、実装コードではない

## 改修手順

1. 既存アプリの起動方法と主要なデータフローを確認する
2. `data/uecport-types.ts` とマスタ JSON の契約を確定する
3. ステージ選択と進捗表示を追加する
4. サーバー側へ写真照合 API を追加する
5. 照合成功時の進捗スナップショットを保存する
6. 解放状態をゲームへ反映する
7. 現地画像でしきい値を調整し、端末横断で検証する
